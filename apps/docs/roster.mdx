# Manage the roster

The **Roster** area is where you add swimmers, maintain their team details, and organize them into groups.

## Add swimmers

Use **Roster → Swimmers** to create a swimmer record. Add the contact and eligibility details your team needs, then update the record when the swimmer’s group or status changes.

Club teams can keep a USA Swimming ID. High-school teams can track class year and school-specific eligibility details.

## Organize groups and coaches

Use the **Groups** and **Coaches** tabs to organize training groups and the staff connected to them. Groups make roster and practice work easier to scan without mixing teams together.

## Import and export

The roster import/export tools accept Project Aqua share packs (`.aqua.json`), CSV, SD3, CL2, HY3, and roster ZIP files.

<Warning>
  Review the import mapping and any unmatched rows before treating an import as complete. An unsupported file type or a missing identity field can prevent a row from being matched.
</Warning>
