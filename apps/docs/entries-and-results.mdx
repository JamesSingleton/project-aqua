# Prepare entries and import results

Use the meet entry workspace to decide who is swimming, set seed times, staff relays, and keep scratches visible without deleting the work.

## Build entries

Start with the roster and the imported event list. Project Aqua can use a swimmer’s best time as the seed time; coaches can still change it for the meet.

For relays, choose the swimmers and review the proposed order before exporting. The available lineup and relay tools depend on the team’s plan.

## Review and export

Before sending the file to the host:

1. Check the events, entry limits, and scratches.
2. Verify relay swimmers and seed times.
3. Export the requested HY3, CL2, or SDIF file.
4. Print entries or a split sheet if the coaching staff needs paper on deck.

## Bring results back

Import HY3, CL2, SDIF, or a ZIP result pack after the meet. Project Aqua compares new results with the swimmer’s prior best and updates faster swims. Keep an eye on unmatched result rows so that an identity mismatch is not missed.
