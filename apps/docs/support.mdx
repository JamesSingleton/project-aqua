# Get help

If a file will not import, a workflow does not look right, or you have a billing question, contact the Project Aqua team from the marketing site’s support page.

## Reporting a product issue

Public bugs and format-fixture issues can also be reported on the [Project Aqua GitHub issues page](https://github.com/JamesSingleton/project-aqua/issues).

## Share useful details

- The team and meet you were working in
- The action you took and the exact message shown
- The file format, not sensitive roster data
- Whether the same workflow succeeds for another file or team

<Warning>
  Do not post a raw coach export containing personal information in a public issue. Share only PII-safe fixtures or contact support privately.
</Warning>
