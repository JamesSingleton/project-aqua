## What Project Aqua is for

Project Aqua is coach software for the team attending a meet. It does not merge other clubs' entry packs, run the timing console, or provide family accounts, messaging, or dues.

## Need help?

Start with the guide for the screen you are using. If something is not working or a file will not import, include the file type and the step that failed when you contact support.
