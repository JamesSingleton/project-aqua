# Plan workouts

Use **Workouts** to create a practice plan for your team. A workout stays connected to the team that owns it, so club and high-school practices never overwrite one another.

## Create a workout

1. Open **Workouts**.
2. Create a workout and give it a useful title and date.
3. Add the sets and coaching notes your staff needs.
4. Connect it to the relevant practice on the calendar when appropriate.

## Keep plans useful on deck

Write the workout so another coach can run it: include the intent, intervals, and any group-specific adjustment in the notes. Project Aqua is designed for a coaching workflow, not a parent-facing practice feed.
